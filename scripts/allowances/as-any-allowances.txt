# Registered downcasts outside the payload data plane.
#
# Read `scripts/check_no_as_any.sh` first. The rule this file exempts from is rule 3,
# which is deliberately the weakest of the three: rules 1 and 2 — no `as_any()` anywhere,
# and no `Any` at all inside `crates/stream/src` or `crates/http/src` — take no exemptions
# and this file cannot grant one. An entry naming a path inside the payload data plane is
# itself a failure.
#
# Format, one per line:
#
#     <path>:<line>    # <why this downcast is not payload negotiation>
#
# The reason is not optional and the line number is checked: an entry that no longer names
# a downcast fails the guard, so an exemption cannot outlive the code it was written for and
# quietly cover whatever moves onto that line next.
#
# What makes an entry legitimate is that the downcast reads a `TypeId`-keyed map the same
# code put the value into. That is dispatch: the type is a lookup key, both ends are in this
# repository, and a mismatch is a misassembled deployment that fails loudly. Payload
# negotiation is the opposite — the two ends are a transport and a body that do not know each
# other, and a mismatch degrades silently into a slower path. "It was convenient" is not a
# reason; add a named accessor to the enum instead.
